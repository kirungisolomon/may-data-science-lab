# May Data Science Lab

A compact data science project that demonstrates exploratory data analysis, visual reporting, and modeling-style metrics.

## Project structure

- `data/sample_health_metrics.csv` contains sample data for a healthcare or operations dataset.
- `src/analyze.py` loads the sample data and computes daily summaries.
- `src/report.py` generates Markdown style analysis outputs.

## Local run

```bash
python -m pip install -r requirements.txt
python -m src.analyze
```
